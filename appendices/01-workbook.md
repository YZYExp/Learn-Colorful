# 附录A 配色观察与实践手册

## 一次20分钟的观察

选一个自己经常接触的对象，例如咖啡包装、应用首页或家中的书桌。先不要取色。记录视线最先落在哪里、停留多久，以及哪些文字需要费力寻找。再用「面积大/小、明度高/低、彩度高/低、与背景接近/分离」描述颜色，暂时不用「高级」或「土」等评价。

接着只提取五个以内的代表色，给每个颜色写一个角色。如果两个颜色的角色相同，试着删去一个；如果一个颜色同时承担警告、装饰和普通链接，分别观察这些用途是否容易混淆。

最后只改一件事：加深正文、减少强调色面积，或把背景改为中性。比较前后两版的阅读顺序。记录的重点不是哪版获胜，而是「哪项修改解决了什么问题」。

## 三组练习与参考判断

**练习1：色卡不变，重做一张海报。** 用墨绿、暖纸、陶橘、深墨，分别做阅读活动与夜间音乐活动。不得新增颜色，但可以改变各色面积、所在位置和是否用于文字。参考判断：两张海报可以通过明暗背景和节奏明显区分。不要把这种结果解释为某个颜色天然属于某种活动。

**练习2：把一张图表打印为灰度。** 如果两条曲线难以区分，先补标签、线型或符号，再考虑换色。参考判断：灰度只是发现部分问题的辅助方法，不等于色觉差异模拟，更不证明所有用户都能读懂。

**练习3：检查同一颜色的四种角色。** 把陶橘分别用作整块背景、大标题、小字号说明、图表标记。写明各自相邻颜色及使用条件。参考判断：背景和大面积装饰可用的颜色，不一定适合小字。能否用作文字必须检查实际前景与背景配对。

## 项目记录表

| 项目 | 记录内容 |
|---|---|
| 任务 | 谁需要看见什么、完成什么行动 |
| 环境 | 手机/纸张/空间，光线、距离、观看时间 |
| 色彩角色 | 背景、正文、主要行动、装饰、状态、数据 |
| 备选方案 | 至少两版，尽量只改变一个关键因素 |
| 验证 | 文字对比、灰度观察、真实尺寸、实际材料样品 |
| 结论 | 保留什么、改变什么、还有什么未验证 |

## 低成本工具如何分工

取色器适合记录数字颜色，不会替你判断语义；对比度计算器适合核对指定配对，不会替你判断整张页面是否好用；色觉模拟器可以帮助发现风险，不代表真实用户体验；软打样有赖正确配置文件和显示条件，也不能替代关键成品的实物确认。

不要因为工具给出一个绿色勾选就停止检查。把工具结果和真实尺寸下的观察放在一起，能够解释自己的选择，比收集更多色卡更有帮助。
