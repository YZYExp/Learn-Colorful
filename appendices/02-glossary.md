# 附录B 易混词与阅读边界

| 词语 | 本书中的含义与注意点 |
|---|---|
| 色相 | 描述红、黄、绿等颜色类别的属性；模型中的角度不是普适的颜料混色公式 |
| 明度 | 对颜色相对明暗的感知描述；不要与所有模型里的L数值或物理亮度直接等同 |
| 彩度 | 颜色偏离相应中性色的程度；与饱和度有关，但不同模型定义不同 |
| 饱和度 | 依模型与上下文定义的属性；HSL中的S并不是独立、均匀的视觉强度刻度 |
| 亮度 | 在日常中文和软件中有不同用法；涉及测量或计算时应说明具体量 |
| 相对亮度 | WCAG对比度计算使用的量，由线性化后的sRGB通道加权得到 |
| 色温 | 光源色度相关的描述；物体的「暖色/冷色」属于另一种相对观察语言 |
| 中性色 | 在指定环境中接近无彩的颜色；暖灰冷灰仍可能带明显倾向 |
| 色域 | 某色彩空间或设备在条件下可表达的颜色范围，不是色彩准确度评分 |
| 色彩空间 | 以确定规则表示颜色的系统，如sRGB；数值必须连同空间理解 |
| ICC配置文件 | 用于描述设备或颜色编码与参考空间关系的数据；不是任意图片的美化滤镜 |
| 色彩角色 | 颜色在设计中的用途，如正文、背景、危险状态，而非某个具体色号 |
| 色彩变量 | 被命名并复用的颜色值或角色引用；需要同时维护使用规则 |
| 同色异谱 | 不同光谱刺激可能在某观看条件下形成相同颜色匹配；改变条件后可能失配 |
| 加色与减色 | 混合光与材料对光的吸收等不同机制，不能用一种色轮包办 |

## 本书没有展开成专业教材的部分

视觉神经科学、分光测色、工业配色、颜料化学、电影调色、舞台灯光和印前生产都有各自的技术体系。本书给出与日常设计判断有关的入口，不把简化示意当作这些领域的完整操作规程。

继续学习时，先判断目标：要更会设计，就增加实际任务与观察；要保证工业一致性，就学习测量、标准和生产容差；要理解视觉机制，就进入颜色科学与视觉研究。它们相互关联，但需要的证据、工具与判断标准并不相同。
