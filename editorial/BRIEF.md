# 《色彩的语言》共同写作约定
副标题：从看懂颜色到建立配色系统。面向兴趣学习的非专业中文读者。
主线：看见颜色→理解关系→控制画面→表达意图→应用于场景→建立系统。
贯穿项目：原创文化空间「间色」（阅读、饮品、小型展览）；基础色为墨绿 #24544B、暖纸 #F6F1E7、陶橘 #C86345、深墨 #202824。不是普适最佳配色，必要时修改。不要捏造真实品牌案例。
每章应有完整叙述、清楚因果、至少一个可执行例子/观察活动及答案方向、条件和限制。目标每章约1600–2500汉字，依题材调整；不用模板式自问自答和口水话。章节间互相补充，避免重复讲色相明度彩度。
事实必须浏览核实，优先标准、官方设计规范、博物馆、研究论文；本章末列资料，并在对应段落放 Markdown 来源链接。文化心理不写普遍因果，趋势不声称年度流行。真实品牌不凭记忆填色号。
精确图由主代理制作，每章预留一个 ../assets/images/fig-NN.png（NN为两位章号），并写能兑现的图注；所有图片由主代理检查实际嵌入。可以在章节中写图的教学意图，但不能交付占位。
每章文件名 NN-英文slug.md，标题 # 第N章 中文标题。仅编辑自己负责章节，来源记录放 references/sources-组名.md；不改共享清单、不提交git。
只写 Markdown，不生成HTML；最终主代理统一整合与检查。共24章，编号/题目见 book.json。
